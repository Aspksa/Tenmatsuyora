# Tenmatsuyora
Локальный интерфейс ИИ: слева живая SVG-карта без бокового меню, справа чат без рамок.

## Windows
Установите Python 3.11+ и Node.js 22+ (Node нужен только для первой сборки). Запустите Start.bat. После сборки приложение работает без Node и без интернета в локальном режиме. База находится в data/history.sqlite3.
Для ответов Cloud.ru перед запуском задайте в PowerShell переменные окружения CLOUD_RU_API_KEY и CLOUD_RU_MODEL. Используйте идентификатор модели из своего аккаунта. Ключ не записывается в БД. Отправка сообщения при настроенной модели вызывает платный API; фоновых запросов нет. Без ключа сообщения сохраняются локально, генерации нет.
Сервер слушает только 127.0.0.1. История не шифруется. SVG-звёзды фона декоративны; узлы сообщений отражают реальные сохранённые записи. Семантическая память, потоковая генерация и инструменты пока не реализованы.

## Stellar Evolution 3.0
Созвездие = 30 записей, полная карта содержит группы всей истории. В обзоре видны агрегаты; последние и выбранные записи раскрываются отдельно. Колесо — масштаб, перетаскивание фона — камера, ◎ — обзор, ✦ — активная группа. Позиции вычисляются детерминированно по номеру группы; ручное положение камеры не сохраняется между перезапусками. Связи геометрические, не семантические. Нагрузка ограничена раскрытием трёх последних и одной выбранной группы, статическим фоном и остановкой кадровой анимации в покое. Геометрический тест проверяет 334 группы, серверный тест — 10000 сообщений; реальная скорость браузера зависит от устройства.

## Organic Universe 4.0
Старые созвездия сохраняют миниатюрные звёзды для реальных ID записей (битовая маска из SQLite), а не декоративные точки. Детальные узлы двигаются с ограниченной амплитудой, связи следуют за ними. Позиции групп детерминированы с нерегулярным смещением, камера и параметры эффектов хранятся в SQLite независимо от локального порта. ⚙ открывает настройки; скорость 0 отключает анимацию, экономный режим уменьшает эффекты. Графические связи остаются геометрическими. Это приближение к референсу, не исходный физический движок видео.

CI дополнительно открывает страницу в Chrome на Linux с 360 тестовыми сообщениями и проверяет реальный DOM (12 компактных созвездий, 90 детальных звёзд и чат). Это проверка запуска, не покадровое визуальное сравнение и не FPS-бенчмарк.
