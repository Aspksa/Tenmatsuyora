# Канон и данные
foundation.json — стартовые авторские предпосылки. После первой публикации неизменяем, кроме специально согласованной миграции. Неустановленное — не факт. Новые факты, персонажи, места, предметы, связи и состояния входят в журнал событий. Важные детали (семья, внешность, способности, ограничения, привычки, возраст, титулы) в досье; обновление через change_profile с прежним значением и новым, по событию. Состояние можно вычислить повторно из всего журнала. Полный текст остаётся литературным источником; автоматическая проверка не умеет доказать, что событие действительно описано прозой. Книги не содержат данные реального пользователя.
