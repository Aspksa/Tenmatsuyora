# Передача контекста
checkpoint.json — контрольная точка с общим кратким пересказом и указанием последней главы, последнего тика и открытых арок. catalog.json хранит резюме каждой главы и её участников, места, темы, сцены, предпосылки. scripts/chronicle.py context выводит вычисленное текущее состояние всех героев, направленных отношений, знаний, фактов и арок, последние резюме и рекомендуемые пути чтения; search ищет по метаданным и полному тексту. При росте романа выбирать нужные главы по источникам, не доверять одному сжатому пересказу.

current.json — материализованное состояние на конец последней опубликованной главы; characters/ID.json — отдельное досье с входящими и исходящими связями, известными фактами и источниками. Они создаются stamp и строго сверяются с replay в CI. Не редактировать их как независимую истину.

Narrative 13 хранит отдельные проверяемые пакеты в narrative/; handover/latest.json читать первым после START_HERE. Исторический снимок компактный, текущий полный — state/current.json. Данные narrative не редактировать вручную как канон: stamp пересоздаёт их по журналу, validate сравнивает.
