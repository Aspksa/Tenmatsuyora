Для продолжения читать [index.json](index.json), последнюю главу с JSON и обязательные [инструкции](../chronicles/START_HERE.md). Следующая глава для написания — 6 «Девять хвостов»; следующая для официальной публикации — 1. Не путать эти номера.

Файлы сохранены без изменения оригинального текста и метаданных; исходные SHA в index.json. base_sha и ссылки на предыдущие ветки в метаданных обозначают происхождение черновиков, а не утверждение, что текущий main не менялся. Перед дальнейшим редактированием сверить новый SHA main и возможные изменения канона. Новые черновики сначала писать в отдельных ветках; архивное объединение в main — только с разрешения автора, после CI. При изменении или публикации архивной главы обновлять индекс и контрольные суммы; при публикации удалить её черновик из архива и перенести в официальный каталог с журналом, stamp/validate и CI. Не добавлять архив в публичную читалку как опубликованный текст.
